# Security Policy

## Supported Versions

Security updates are provided for the latest release of each active project. Older versions may not receive patches.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately:

- Use GitHub's **Private Vulnerability Reporting** feature on the affected repository (Security tab -> Report a vulnerability).

Do not open a public issue for security vulnerabilities.

## What to Include

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested mitigations

## What NOT to Include

- Never include real credentials, tokens, API keys, or private user data in reports.
- Do not publicly disclose the vulnerability before it has been addressed.

## Response

We will acknowledge receipt and work to address valid reports in a timely manner. We appreciate responsible disclosure.
