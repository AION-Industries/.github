# Support

## Getting Help

- **Issues**: For bugs and feature requests, open an issue in the relevant repository.
- **Discussions**: For questions, ideas, and general discussion, use GitHub Discussions where available.

## Before Opening an Issue

- Search existing issues to avoid duplicates.
- Provide clear reproduction steps for bugs.
- Include relevant environment details (OS, versions, etc.).

## Security Issues

Do not report security vulnerabilities through public issues. See [SECURITY.md](SECURITY.md) for responsible disclosure.

## Response Times

AION Technologies is an independent initiative. Response times may vary. We appreciate your patience.
